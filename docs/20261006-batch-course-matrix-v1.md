## 本轮计划与边界

1. 读取实际课程、大纲和指标；当前24门课程，其中软件项目管理已有12条锁定映射，C++高级程序设计最新23版已有1条手写映射，其余22门当前矩阵为空。
2. 按课程主题选取相关指标，配置支撑权重、课程目标和分解说明；不同课程不机械填充全部12类。重复名称的自动化测试课采用相同建议。
3. 软件项目管理保留原锁定矩阵；其他课程创建独立新草稿版本，原大纲与历史指标原样保留。C++高级程序设计复制现有手写映射至新草稿并补充其余相关项，不改写“111”。
4. 新草稿绑定RECOMMENDED-12；课程目标、每条新增映射描述显式标为“示例草稿·待确认”，状态DRAFT，不自动锁定或申报认证。
5. 通过对应教研室主任的正常API保存，每门课程原子提交；先完成全量只读预检和可复核的JSON方案，再执行用户已授权的批量写入。脚本密码与JWT只在进程环境/内存，不保存。
6. 保存前比对原课程快照，保存后验证全部课程最新矩阵、编号/类别匹配、目标引用与H/M/L，并核验历史大纲/指标未被修改。重复运行跳过已完成批次，不重复新增。
