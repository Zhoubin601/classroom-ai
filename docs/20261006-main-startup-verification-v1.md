## 已发现的冷启动阻塞

- 使用原 main 的 Compose 初始化目录在全新 mysql:8.0 容器上复现失败。
- 执行顺序为 01_schema → 02_lab2_migration → 03_us01_us02_integrity → 04_us03_term_lock → 05_us04_archive；尚未执行 initialize.sql。
- 05_us04_archive.sql 第 4 行失败：ERROR 1146 (42S02)，classroom_ai.t_course_offering 不存在；容器退出码 1。
- 原因：整目录挂载使增量迁移按文件名先于完整基线执行；单测和已有数据库无法证明这条新环境路径可用。
- 在 codex/main-startup-fix-20261006 隔离分支将 Compose 改为只挂载完整 initialize.sql；增量迁移文件保留，避免对已有业务库实施重灌。修复已本地提交，尚未推送或合入 main。
