# 五条故事验收运行指南

## 环境和边界

Windows PowerShell、Java 21、Maven、本项目 npm 锁定依赖、Python、Docker 和 mysql:8.0.36。浏览器使用 Playwright 和 Chromium。无需摄像头或 GPU。离线运行需预先缓存依赖和镜像；新机器缺少依赖时应先按各模块锁文件安装。

普通回归：在仓库根执行 `./scripts/run-tests.ps1 -Offline`，覆盖后端、前端单测、类型检查、生产构建及无硬件 Python 回归。

## 真实 MySQL 与浏览器

1. 在 frontend 执行 `npm ci`（已有安装可跳过）、`npm run build`。
2. 在 frontend 启动 `npm run preview -- --host 127.0.0.1 --port 15173 --strictPort`。
3. 在另一 PowerShell 配置 `PLAYWRIGHT_MODULE` 为可用 Playwright 模块目录，`US0102_CHROMIUM_PATH` 为本机 Chromium 可执行文件路径；使用默认安装时可省略。
4. 设置 `$env:US0203_BROWSER='true'`，执行 `./scripts/run-us0102-mysql-tests.ps1 -Tests 'CourseBrowserMysqlTest,CourseSchedulingMysqlTest,CourseWorkflowMysqlTest'`。
5. 结束后移除当前终端的 US0203_BROWSER 环境变量，关闭自己启动的 preview。

脚本只连接新建临时 MySQL 容器的 127.0.0.1:13316/us0102_test；端口占用会失败，不停止其他容器。容器退出自动清理。账号密码在测试运行时随机生成，实际登录页面经过生产 JWT 过滤器；不需要人工填写或保存测试凭据。

完整界面流程：主任下载 JWT 模板并导入课程 → 教师草稿/发布/再次发布与两窗口冲突 → 主任维护多教师、95 人名单、文管 A447 排课及冲突 → 督导授权专业/教师/学期/关键字检索与越权检查 → 主任归档、教师查看历史与空结果。其余模块不计入本轮完成量。

业务接口和数据库真实执行；测试应用只装载与验收有关的控制器，教师/学生字典由测试控制器读取真实数据库，大纲指标接口返回空测试列表。因此本测试不等同于其他所有模块或部署环境验收。

## 迁移与历史数据

现有库先备份并核对 scripts/deploy/mysql/init/ 中 02、03、04、05 增量迁移的适用基线；不要用 initialize.sql 重建已有库。04 创建学期锁表；05 增加归档时间、操作者及展示快照，并输出只读待核对清单。测试验证 05 从缺少新增列的结构执行两次，未知归属及原人数不被改写。

TeachingDataInitializer 默认不自动写入样例；只有显式 app.seed-demo=true 才启用，且已有课程时跳过。真实业务数据的专业、教师关系、历史快照缺失需要核对，不能自动猜测补齐。

## 发布门槛

人工 diff 审查、页面验收及七项材料确认见同目录七项交付清单。通过后创建全新标签和递增源码包（不得移动旧标签），包内应包含源码、运行指南、迁移、合成样例测试、实测证据和 Git bundle；随后在独立空目录恢复并复跑上述验收。该正式发布与源码包恢复目前尚未执行。
