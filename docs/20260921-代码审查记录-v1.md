## 二、 分支改动核验与合规性检查

本次审查针对已推送的 `origin/feat/exp2-supplement-auth-fix` 分支展开，重点复核 Sprint 1 五条用户故事（US-01、US-02、US-03、US-04、US-06）的技术实现与前期探针发现项的修复闭环情况：

### 1. 公共身份认证与 RBAC 权限控制
- **路由安全策略**：`SecurityConfig.java` 实行严格的“默认拒绝（Deny by Default）”，非公开路由一律要求登录（`anyRequest().authenticated()`）；全面下线了未受控的公开注册路由 `/api/v1/auth/register-supervisor`。
- **动态权限同步**：`JwtAuthenticationFilter` 在每次请求拦截中，自动查询数据库 `UserAccount` 同步最新的 `authorizedMajors`，彻底解决 JWT 签发后授权变更无法实时生效的问题。
- **主任专属管辖**：`DirectorController` 实现督导账号建档与专业授权；严格限制主任只能为督导赋予其本教研室管辖的专业，越权授权直接抛出 403 Forbidden。
- **密码编码规范**：采用 BCrypt 安全哈希，并向下平滑兼容内置测试账号历史明文。

### 2. US-01 课程录入与两阶段 CSV 规范导入
- **两阶段导入流程**：`CourseImportServiceImpl` 实现“上传预览校验 → 内存/缓存暂存 → 二次确认批量入库”两阶段机制。
- **输入校验与学时守恒**：严格校验课程编码唯一性、专业存在性、先修课程引用合法性；补齐缺失学时后进行学时守恒校验（`theoryHours + practiceHours == hours`）。
- **确认防抢占与回滚**：导入批次绑定操作人，严格拦截越权确认，防止他人请求非法消耗批次；确认阶段在事务内全量重新校验引用有效性；集成 Spring `TransactionSynchronizationManager`，事务异常回滚时自动恢复缓存批次，并保证 `CourseImportLog` 审计日志记录的事务一致性。

### 3. US-02 课程简介草稿与发布 (版本隔离与并发控制)
- **草稿/发布态解耦**：暂存草稿允许内容缺失；正式发布强制校验简介、考核方式、教学目标三项必填齐全。
- **并发锁与版本隔离**：`CourseContentController` 在事务内引入 `lockCourse` 数据库行排他锁，并实行严格的 `checkedDraft` 校验（强制要求前端上报 `draftId`、`lockVersion`、`publishVersion`），有效防御跨草稿周期的乐观锁失效与过期覆盖缺陷（彻底闭环 09-19 探针 08、09、10）。
- **读取鉴权**：查询已发布内容（`getPublishedContent`）补充 `validateCourseRead` 鉴权，防止督导绕过列表直接按 ID 越权查阅未授权专业的课程。

### 4. US-03 开课统筹与多教师排课防冲突
- **多教师与名单一体化**：支持同一班次关联多名授课教师（主讲+协同），选课名单依托 `OfferingStudentEnrollment` 实体进行规范化维护。
- **双维度冲突检测**：`ScheduleConflictService` 全面覆盖教室占用冲突和教师时间冲突（主讲与所有协同教师均参与重叠时段排查）。
- **学期级排课并发排他锁**：`AcademicTermLockService` 基于 MySQL `t_academic_term_lock` 行级锁实现学期维度的串行化排课，多学期迁移时按学期名称自然排序获取锁，杜绝了高并发排课下的数据击穿与死锁隐患。

### 5. US-04 历史开课、学生人次与归档快照
- **人数与人次统计口径**：在读班次人数根据实际选课名单动态统计；筛选范围内各班次人数累加为累计人次；多教师同一班次只汇总一次，避免重复统计。
- **结课归档与快照冻结**：`CourseOfferingManagementService.archive` 采用排他锁，计算选课总人数写入 `snapshotStudentCount`，置 `isSnapshotFrozen = true`，生成微秒精度的归档时间与操作人，并保存完整的不可变 JSON 快照（`OfferingHistorySnapshot`）；方法具备严格的幂等性，归档后禁止普通修改。

### 6. US-06 组合检索与督导权限
- **多条件 AND 组合检索**：`CourseOfferingQueryService` 支持按学期、专业、教师 ID、课程关键字进行组合筛选。
- **督导权限强制下钻**：督导角色查询时，服务端始终强制叠加 `authorizedMajors` 白名单，空专业或未授权专业在底层直接过滤，无法绕过。
