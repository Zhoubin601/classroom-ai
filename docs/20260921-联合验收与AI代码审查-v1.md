## 本次审查发现与处置

1. ID 列表用 contains(null) 检查，在 Java 不可变列表下抛空指针。改为逐项空值检查，同时显式校验主讲教师非空；真实 MySQL 用例验证合法列表和人数统计。
2. 归档首次返回时间含纳秒，数据库回读只有微秒。归档时统一微秒精度，幂等归档前后时间一致。
3. 主任更新督导授权会清除其他教研室的授权。改为事务内账号行锁，只替换本人管辖的专业，保留其他授权；单测验证越权追加被拒绝和跨教研室授权保留。前端编辑只发送当前主任可管辖专业。
4. 督导页身份和授权范围写死。改为当前登录账号与服务端授权专业字典，浏览器断言实际身份显示。
5. 浏览器测试曾误匹配隐藏 option、误将含归档时间的单元格按纯文本查找。已修正定位；没有通过放宽 HTTP 状态或业务断言掩盖失败。
6. 新增归档迁移测试从缺少新增列的结构执行两次，原有未知归属记录、班次字段和人数保持一致，未补造归档时间或快照。
