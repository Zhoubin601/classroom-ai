日期：2026-10-07。用户已要求修复关联审查发现的问题，依据`20261007-association-audit-v1.md`及其原始诊断结果，业务起点68255ad。

## 本轮采用的实现规则

- 考勤保留现有主任、任课教师、授权督导的使用方式，但所有读写均校验具体教学班范围；操作身份来自当前服务端账号，冻结班次不能新写考勤。当前会话支持按所选班次查询。
- 账号不存在、令牌ID与当前身份不一致时不建立认证；旧令牌不转授给同名重建账号。
- 教学班创建后的课程不可通过普通编辑替换；课程已有教学班、大纲或资源时不能原地换专业。无关联记录的课程可校验后换专业。
- 明确任课教师可读取所授课程专业目录，公共目录写权限仍仅牵头主任；授课关联不扩张教师所在教研室管理范围。
- 指标类别由绑定目录校验，完全相同的指标/目标映射拒绝重复，允许同编号不同目标独立映射；统一整份和单条操作的历史保护。省略目录版本保留已有绑定，已有引用的目录只能原样重导，内容变化要求新版本。
- “无”作为空先修；新建/变更先修禁止自身、循环和未知引用。旧未知引用原样保留时不阻塞其他字段编辑，修改名称不让旧名称引用悬空。先保留现有文本格式，不在缺少资料时创造外部课程或猜测别名。
- 数据治理仅处理有确定依据的CS3003自身先修，保留原文备份与变更证据；不替换8门课程未匹配名称，不重绑旧大纲、不重导示例矩阵。

## 执行和验证计划

1. 服务端权限、归属、指标/目录版本与先修公共规则修复。
2. 有针对性的回归测试和HTTP权限测试；隔离MySQL验证真实事务、并发与目录保护。
3. 前端去除姓名推断权限并按班次读取当前会话，验证类型、构建和正常考勤流程。
4. 数据只读快照、确认修复无误后更新日常后端，记录明确的数据修正与保留项。

本文件为过程记录，不是学校正式制度；本轮暂不提交/推送，保留raw、历史output及现有未跟踪资料。实际完成结果将在验证后追加。

## 修复完成结果

2026-10-07完成六类整改。本机后端已更新为新JAR，前端Vite读取当前源码；旧后端镜像保留为`classroom-backend:before-association-20261007`。本轮未提交或推送Git。

1. **考勤范围与身份**：会话、历史、开始、结束、实时更新均校验具体班次；教师包括显式协作任课关联。操作身份从数据库账号生成，忽略客户端身份字段。冻结班次禁止写入，当前会话按班次查询。前端使用服务端授权班次，快速切换丢弃其他班次的迟到响应。
2. **旧令牌**：带ID的JWT必须对应当前数据库同一账号；删除及同名重建账号不继承旧令牌。每次重载角色/专业权限。`/auth/me`也仅返回已校验身份，禁止独立从令牌声明恢复账号。无ID旧令牌保留用户名兼容，不声称能够追溯其同名重建历史。
3. **归属保护**：班次普通编辑不能换课程；课程已有教学班、大纲、指标、资源或修订时不能原地换专业或删除。无关联课程可校验后换专业，继续显式检查专业牵头/参与及教研室范围。
4. **跨室任课目录**：实际授课教师可读取该课程专业目录，授课关联不扩展目录写权限或专业管理范围。
5. **矩阵与版本**：整份和单条写入校验编号所属类别、权重及相同目标集合重复。历史与锁定大纲禁止原地修改，允许复制新版本。遗漏目录/目标保持原内容，新版本复制目标和映射。已被大纲引用的目录只允许原样重导，变化须新版本；课程/专业行锁与事务隔离防止并发重复及版本漂移。
6. **先修关联**：“无”合法，新/变更引用禁止自身、循环及未知引用；名称歧义要求编码，已解析的新引用保存稳定课程编码。被先修引用的课程不可删除，改名前保护旧名称引用。未匹配旧文本原样保留时允许编辑其他元数据，不猜测外部课程或别名。
