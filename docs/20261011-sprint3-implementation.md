## 数据与事务

Spring JPA 增量创建/补列后，Sprint3Migration 执行幂等数据迁移和约束补建。旧资源逐条生成独立系列；先补系列和版本归属，再建立当前指针，兼容已有复合外键。已存在约束不重复创建，已允许NULL的评分列不再重复DDL。未知历史权重保持NULL；旧建议整体迁一条并标记自动迁移。

发布模板事务锁定草稿及模板族，发布版本唯一约束为(family_id,number)。评价在提交事务中锁定记录、读取发布版本并保存权重快照；只接收模板ID和维度得分。草稿、片段、资源系列、建议和反馈使用版本；相同内容保存也有服务端更新时间，防止版本不递增。反馈首次期望0，落库后版本1；随后每次有效更新递增并追加历史。

课程范围与有效开课筛选共用。A要求审核人、审核时间及合法状态；B另外要求publishTime≤asOf。教师明细不携带评价人/审核人身份。读取不发布评价、不改变状态。跨版本总分均值独立，正权重缺失不补0；完整评价总分为原始四维之和；未知权重单列。

资源列表默认每系列当前版，旧ID固定历史。共享策略/epoch保存在系列；长时间响应完成前通过新事务读取已提交授权，票据绑定申请人和固定版本。资源直链禁止；预览使用no-store和申请人水印。新旧前端预览每5秒重新鉴权并释放Blob。

资产上传/导入以及片段挂载/修改统一校验六环节枚举，来源类型、说明、声明必填。外部来源引用只记录，导入受控文件；不下载外部URL。服务器ffprobe探测视频流，整数毫秒，10秒超时、有限输出；422表示无法获得有效时长，503表示工具不可用。文件变化拒绝播放，替换资产创建新片段。分析结构和32KiB限制服务端执行，管理员复核后才对普通授权用户展示。

## 已定位修复

- 稳定账号归属改为工号关联，旧按姓名测试调整为同名不同账号的拒绝用例。
- 保存相同内容必须递增记录版本，否则两个旧窗口均会成功。
- 资源系列已有复合外键时，迁移必须先补版本归属再设置当前指针。
- 管理员/me、/logout属于登录会话入口，必须在通用业务拒绝规则前允许已认证账号。
- 配置的资源文件目录必须生效，写入性测试使用独立目录。
