# US-01 / US-02 修复与验证记录

日期：2026-09-19。范围：实验二 US-01 / US-02 检查中发现的问题，以及修复过程中发现的草稿加载竞争与历史创建人误记问题。

## 修复结果

| 原问题 | 实现与验证 |
|---|---|
| 督导导入、主任跨教研室导入、新增档案缺少权限 | SecurityConfig 限定主任路由；CourseArchiveRules 在手工建档、预览、确认阶段再次校验主任身份、课程教研室和专业字典归属。修改档案检查旧归属和提交后的归属。 |
| 已发布内容可按 ID 越权读取 | published 接口使用统一课程授权；实际 HTTP 过滤链测试验证未登录 401、未授权专业 403、已授权读取 200。 |
| 教师姓名子串/同名误授权 | 仅按教师工号、开课班次及关联表确定任课关系，姓名仅作展示。无关联教师不能读工作草稿或发布。 |
| 旧页面跨草稿/跨发布周期覆盖 | 强制提交 draftId、lockVersion、publishVersion；缺失或过期返回 409；无草稿时不再隐式发布。课程行锁持续到事务提交，READ_COMMITTED 保证等待锁后的读取可见最新版本。 |
| 首次并发建立重复草稿、锁版本返回不及时 | 草稿获取/保存/发布均使用同一课程锁；saveAndFlush 后返回实际锁版本；发布时把历史重复草稿保留为 SUPERSEDED，防止旧草稿重新变成当前草稿。 |
| CSV 分项学时缺失导致合计错误 | 手工和 CSV 使用同一补齐规则：只缺一项按总学时减另一项补齐，两项均缺默认为全部理论；验证非负整数与守恒，学分拒绝 NaN/Infinity。 |
| 手工专业与先修引用缺少校验 | 专业必填且必须存在并属于主任管辖范围；先修编码/名称必须存在。已有课程编码设为不可原地更改，避免已有字符串引用失效；页面同步只读。 |
| 确认阶段不复核引用 | 确认重新校验当前专业、教研室范围、先修引用、数值、编码重复；仍支持批次内引用。 |
| 越权请求消耗他人批次 | 先校验创建者，再原子占用；并发合法确认只能一个成功；事务失败后恢复批次，便于重新校验后重试。 |
| 总行数把字段错误当作多行 | totalCount 使用数据记录数，errorCount 按错误行号去重，errors 保留每个字段错误详情。 |
| 审计异常被吞掉 | 审计与课程同一事务，异常整批回滚；手工录入/导入记录 createdBy、updatedBy。旧档案创建人未知时保持为空，只更新本次编辑人。 |
| 前端草稿加载失败后使用默认版本、异步覆盖输入 | 加载失败明确提示并禁用提交；完整传递三个并发字段；移除重复加载，过滤过期响应，切换课程时清空旧草稿。草稿未加载或正在提交时禁用输入，防止迟到响应覆盖输入。 |

主任专业列表同步改为明确的字典教研室归属，移除“猜测专业/默认 SE”的授权兜底。保留检查前已有的导出、自适应表头及其他未提交修改；未修改 raw 原始资料、未提交 Git、未创建发布标签。

## 使用前需复核

1. 现有业务数据库未应用迁移脚本；使用旧数据库前按运行流程备份并执行 03 迁移，再重启后端和更新前端。不要仅刷新旧页面继续使用旧 DTO。
2. 教师账号须有真实工号与班次关联；专业字典须有明确教研室归属。缺失数据现在会明确拒绝授权，不能再依赖姓名或专业猜测通过。
3. 本轮没有更新旧发布标签和源码压缩包；后续正式交付需重新绑定最终提交。
