# 具身机器人智能课堂分析系统 - 前端可视化大屏与教师管理中心 (Classroom Frontend)

本项目为智能课堂分析系统的前端大屏与管理应用，基于 **Vue 3 + Vite 5 + TypeScript + Tailwind CSS + Apache ECharts** 构建，直连 Spring Boot 3 后端微服务（默认 `http://localhost:8080`），提供暗黑科技风格的实时教学状态监控、时序专注度波形渲染与人脸库管理。

---

## 一、 功能亮点与模块构成

### 1. 实时大屏指挥中心 (`DashboardView.vue`)
* **核心指标卡片 (Metric Cards)**：实时展现实到人数、应到总数、出勤率(%)、实时平均抬头率(%)、低头走神预警人数、专注度综合评级；
* **ECharts 抬头率动态波形图 (`FocusTrendChart.vue`)**：平滑渐变面积折线图，X 轴为时间戳，Y 轴支持抬头率百分比与在座人数双曲线，反映学生听课注意力随教学进度的流动变化；
* **学生在座与姿态矩阵网格 (`StudentStatusGrid.vue`)**：卡片式展现全班学生头像、学号、姓名，并通过呼吸灯与动态徽章标记状态：
  * 🟢 **抬头听课 (UP)**
  * 🔴 **低头走神预警 (DOWN)**
  * ⚫ **未出勤 (ABSENT)**
* **内置演示推流控制器 (Simulation Controller)**：支持一键开启/暂停“模拟推流”，在尚未连接物理摄像头或现场离线演示时，自动模拟生成连续且逼真的专注度与姿态时序流。

### 2. 学生档案与人脸库管理中心 (`StudentManageView.vue`)
* **学生档案列表表格**：查看学号、姓名、性别、班级、512 维特征录入状态与底库照片；
* **人脸数据快速录入**：支持新学生建档、512 维特征向量持久化录入与底库照片附件上传；
* **1:N 云端人脸比对测试工具**：调用后端 `/api/face/search`，以滑块实时调节判定阈值（默认 0.45），即时验证特征向量比对准确率并展示匹配得分。

## 二、 快速运行指南

### 方式一：使用一键启动脚本（推荐）
在项目根目录运行：
```powershell
.\scripts\start_frontend.ps1
```
脚本将自动检测并安装依赖，随后启动 Vite 开发服务器。

### 方式二：手动命令运行
```bash
# 1. 进入 frontend 目录
cd frontend

# 2. 安装 npm 依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 生产打包
npm run build
```
启动成功后，在现代浏览器中访问：**`http://localhost:5173`**。
