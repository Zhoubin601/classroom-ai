## 摄像头接入缺口

`vision/classroom_monitor.py:296` 的 `async_send_stream_report` 向本轮真实后端发送合成零人帧，实际收到 HTTP 401。该请求没有 `Authorization`，帧载荷没有 `offeringId`，发送异常被静默忽略。

为避开摄像头/GPU 模型依赖，诊断通过 AST 提取当前源码中的原始发送方法执行，仅将后端地址指向独立测试服务；HTTP 传输未模拟。它证明发送方法接入失败，不证明现场摄像头识别效果。

`frontend/src/api/index.ts:74` 的启动调用与 `frontend/dev/camera-plugin.mjs` 的 Python 启动路径尚未将所选班次及认证上下文传给原生发送链路。仅补认证仍不足以完成接入：已认证但没有班次信息的推流请求也会被拒绝。本轮没有自动修改业务源码；后续需贯通班次、认证、原生推流及错误反馈，再做现场识别验收。
