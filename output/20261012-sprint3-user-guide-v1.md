# Sprint 3 使用说明

版本交付日期：2026-10-12。适用分支：`exp4`。包含US-11、12、16～21八条故事。依据实验一《第二组_项目规划方案.docx》及用户确认的完整修订计划；原规划排期2026-10-12～23不变。

## 启动和管理员初始化

项目目录：`D:/2026Autumn Semester File/classroom-ai-demo`。打开Docker Desktop后，在项目目录执行：

```powershell
.\start_project.ps1 -Rebuild -NonInteractive
```

此命令重建新后端镜像及启动项目；Dockerfile已安装ffmpeg/ffprobe。已有数据库在JPA补列及Sprint3Migration中增量升级，旧资源逐条建独立系列，不按同名合并。不要手工删除旧文件或重置业务库。

直接在本机运行Java后端时，先安装探测工具：

```powershell
.\scripts\setup-video-tools.ps1
$env:CLASSROOM_FFPROBE = (Resolve-Path .untime	oolsfmpegfprobe.exe).Path
& $env:CLASSROOM_FFPROBE -version
```

后端启动会预检探测工具。缺失时视频导入返回503；无法读取有效时长返回422。其他课程功能可正常启动。前端无法解码的视频需要用支持的编码重新导入；验收样例为H.264 MP4。

ADMIN只通过显式初始化创建，不通过公开注册或主任督导建档授予。第一次启动前配置唯一、未占用的用户名和密码：

```powershell
$env:CLASSROOM_ADMIN_BOOTSTRAP_ENABLED = 'true'
$env:CLASSROOM_ADMIN_USERNAME = '自行选择未占用的管理员账号'
$sprint3Secret = Read-Host '输入初始化密码' -AsSecureString
$env:CLASSROOM_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', $sprint3Secret).Password
.\start_project.ps1 -Rebuild -NonInteractive
Remove-Item Env:CLASSROOM_ADMIN_PASSWORD
$env:CLASSROOM_ADMIN_BOOTSTRAP_ENABLED = 'false'
```

不要把密码写入文件或提交到仓库。已有同名ADMIN不会重复建号或重置密码；同名其他角色会报错，不提升其权限。用户名唯一约束保护并发创建。登录使用常规登录表单，管理员只显示“统计与反馈”“微格教学视频”。

## 四角色入口

| 角色 | 使用方式与权限 |
|---|---|
| ADMIN | 管理模板、受控授权视频、片段、分析复核；只读取必要课程目录；不能访问评价审核、教师反馈、通用课程管理、考勤和学生人脸 |
| 主任 | 本教研室课程内维护微格、查看质量汇总/预警、审核评价、导出、切换资源当前版 |
| 教师 | 通过登录账号工号关联主讲/协同授课课程；维护关联课程微格/资源；只读开放后的本人评价与建议，维护自己的行动反馈 |
| 督导 | 授权专业内读取；在本人草稿/驳回评价下维护独立建议；按课程类别查看已审核问题分布；不能维护微格 |

姓名用于显示和报表文字筛选，不能决定教师归属。同名账号不能相互取得课程或反馈。教师在同教研室可读取共享课件，但不能因此维护不关联的课程或下载只读共享课件。

## 模板和评价

管理员进入“统计与反馈”，填写模板名称、场景、四维说明及权重。教学态度、内容、方法、效果四维权重非负、最多三位小数，必须精确合计100%。保存草稿后可编辑，点击“发布不可变版本”后普通更新不能再修改。

调整已发布模板时，点“基于此版本新建草稿”，重新保存和发布。发布版本有独立ID和版本号；发布新模板不会修改已有评价。

督导在原工作台开始评价时选择已发布模板。维度原始得分不得超过该维度权重；权重为0只能填0或留空。草稿绑定原版本；明确换模板才重新校验已有分数。评分、权重快照和总分由服务器校验并在同一事务保存，前端不能传权重或总分。

草稿可缺失正权重维度；正式提交必须全部填写，0分合法。正式提交仍需听课主题、至少3条不同亮点和建议。主任审核后，教师反馈等待配置延迟（默认24小时）开放。建议维护会更新父评价版本，提交前重新打开草稿以读取最新版本。

## 统计口径和反馈开放

“已审核集合A”要求审核人、审核时间齐全，且状态为APPROVED_PENDING或PUBLISHED。“反馈开放集合B”还要求publishTime已配置并不晚于本次查询asOf。

覆盖率、主任汇总/导出和督导问题统计使用A；教师明细、雷达、建议、反馈证据使用B。刚审核但延迟未结束的评价可参与管理统计，教师仍看不到它；查询不会主动发布评价。

覆盖率分母为所选学期有效开课课程，分子按课程去重。草稿、待审核、驳回和无完整审核凭据的记录排除。

评分显示遵循：

- 正权重维度百分制值=得分÷该版本权重×100；零权重“不适用”，不参与维度均分。
- 缺失不补0；缺失正权重的评价退出总分均值/低分预警，审核后仍可计入覆盖率。
- 完整评价总分为四维原始得分之和，0～100。不同版本分别计算总分均值和预警，不混算。
- 历史权重未知保留原分，单列旧版统计。页面中的LEGACY_UNKNOWN表示“旧版口径未记录”，NO_EVALUATION表示“暂无审核评价”，T后数字为模板版本ID。未知权重不参与雷达归一化或新模板低分预警。
- 雷达轴显示有效样本数；缺少有效轴时不虚构完整多边形，查看数据表。

主任预警默认低分阈值75、低覆盖阈值30，零覆盖独立列出。可用`CLASSROOM_LOW_SCORE_THRESHOLD`、`CLASSROOM_LOW_COVERAGE_THRESHOLD`配置并重启。预警显示配置来源和样本，必须人工复核，不作为自动考核结论。

## 按课程类别查看问题

督导进入“统计与反馈”，选择学期及“课程类别”。类别来自当前授权专业、所选学期有效开课课程的`Course.courseType`，与主任端课程性质一致；它与问题标签是两个维度。

“全部类别”按类别分别展示标签图表和数据表。“未分类”对应空类别，不推断归属。指定类别仅显示该类别；没有评价的类别显示空状态。

每组显示课程数、审核评价样本数、已标注/未标注数。标签同评价去重，百分比分母为该类别全部审核评价；一条评价可有多个标签，比例合计可能大于100%。展开明细可查看课程类别、来源评价ID和分类版本，不据此输出排名。

示例标签为目标说明、内容组织、教学互动、教学方法、学习效果、其他，由评价表单保存并随评价审核；不会从评语自由文本自动猜测。

## 下载报表

主任在“统计与反馈”使用学期、课程类别、课程关键词和教师筛选，再点“查询”。页面每页20条；Excel/CSV下载包含**全部筛选结果**，不是当前页。

Excel含“汇总”“评价明细”两表，均来自同一MySQL REPEATABLE READ只读事务快照，首行记录asOf。CSV为同一口径的汇总，并记录快照时间。导出处理逗号、换行、双引号、公式开头文字、XML特殊字符及非法控制字符，不生成公式单元格。

没有混合模板总均分；旧版原分单列。教师通过独立脱敏详情读取，不使用主任导出DTO。记录ID用于回查，不能绕过原权限和反馈开放时间。

## 资源历史版本和撤销共享

先在原课程资源入口上传文件。然后进入“统计与反馈”下方“资源历史版本”，选择当前资源，查看固定资源ID、版本号和上传时间。

有课程写权限时，可在同系列上传新版；上传成功会设为当前版。主任可以点历史行“设为当前版”。新上传和切换均使用系列记录版本，旧窗口会返回409；刷新后重新操作，不能自动覆盖别人修改。

列表默认每系列当前版本。**旧资源ID永远对应固定历史文件**；`GET /api/v1/resources/series/{id}/current`通过当前指针解析；历史入口为`GET /api/v1/resources/{resourceId}/history`。

共享策略作用于整个系列。在原资源维护界面撤销共享后，后续旧ID、预览票据和下载均重新鉴权；直链始终禁止。授权预览加申请人水印，使用no-store；已打开预览每5秒复核，失权后关闭并销毁Blob/画布状态。若仅上传或切换当前版，没有撤销共享，授权用户仍能按历史ID查看原版本。

已下载、已传输或截图的内容无法收回；撤销只能阻断后续平台访问。移除资源保留历史文件，不破坏引用。

## 授权视频、片段和分析元数据

进入“微格教学视频”。管理员可选必要目录中的课程；主任/教师仅能在自身课程范围内维护；督导只读授权专业片段。

1. 选择资产教学环节：B导入、O目标、P1前测、P2参与式学习、P3后测、S总结。标签不得空白或使用其他值。
2. 来源类型选PLATFORM_UPLOAD（平台上传）或AUTHORIZED_IMPORT（授权导入）；填写来源说明（128字内）及授权声明（1000字内）。导入还需来源引用（512字内），URL只允许HTTP(S)，不能填本地路径。引用只记录，不自动下载。
3. 选择MP4/WebM文件（100MB以内）并导入。服务器读取视频流和时长，记录内容哈希、提交账号和时间。浏览器上报时长不能替代服务器探测。
4. 选择受控资产，填写片段标题、合法教学环节和整数毫秒区间，满足`0 ≤ startMs < endMs ≤ durationMs`，挂载片段。
5. 回看从起点开始，到终点暂停；拖动超出区间会被限制。来源文件没有自动切片，授权客户端仍可能取得完整视频。

替换视频要新建资产和片段，不能覆盖原文件或静默迁移旧区间。底层文件哈希变化会拒绝播放。移除课程片段记录不删除仍可被引用的资产。历史缺失来源、声明、标签或资产验证的数据显示“资料未提供/未验证”；可选择新受控资产补录历史片段并校验，验证前不能回看。

分析元数据可不填。提供时结构如下；以下仅说明格式，不代表实际观测数据：

```text
schemaVersion: 1
source: 128字符内来源文本
observedAt: 带时区时间，例如2026-10-12T09:00:00+08:00
metrics: 最多100项
  name: attendanceRate 或 lookUpRate
  value: 0～100
  unit: percent
  startMs/endMs: 资产内合法整数毫秒区间
  confidence: 可空；提供时0～1
note: 最多1000字符
```

对象序列化后不超过32KiB，未知字段拒绝。分析source不能替代资产来源/授权声明。管理员可查看“待复核分析”，复核后才对其他授权用户显示；修改分析数据会清除此前复核状态。不补造指标或置信度。

## 独立建议和行动反馈

督导先在工作台暂存评价草稿，再进入“统计与反馈”的“维护独立建议”，选择本人草稿/驳回评价。可添加多条建议，也可按建议ID编辑；每条最多2000字，可单独选择BOPPPS标签和证据。建议随父评价提交、审核；旧文本整体迁为一条，不自动拆分。

证据最多10项，引用格式：

```json
[{"type":"EVALUATION","id":123}]
```

type仅为EVALUATION、RESOURCE_VERSION、MICRO_SLICE；ID需真实存在、同课程且引用人有权限。视频可另填合法startMs/endMs，并位于片段范围内。不要填写文件路径。这里的123仅为格式占位，需替换成有权限的实际ID。

教师反馈时间到后，在“建议到行动”选择“接受”或“调整”，填写行动内容（2000字内）及实践反馈（4000字内），可补合法证据和教学环节。每位主讲/协同教师维护自己的一份记录；其他同名账号不能编辑。

首次保存expectedVersion为0，保存后成为1；后续以读取的记录版本保存。双窗口旧版本返回409；刷新后核对已有内容再修改。当前记录和修改历史同事务保存；操作者、时间、版本及变化由服务器追加，不能在请求中提供历史或教师ID。

教师查看建议、反馈及历史证据时会再次验证开放时间与可见性。不可见引用只显示“证据不可访问”，不暴露路径、名称或评价人。

## 常见错误及验收复现

| 错误 | 处理 |
|---|---|
| 400 | 检查标签、来源声明、权重、评分、区间、证据或元数据结构 |
| 403 | 核对账号角色、教研室/专业/授课关联、共享策略和反馈开放时间 |
| 409 | 记录被修改、已发布不可更新或文件完整性异常；刷新核对，必要时新建版本/资产 |
| 422 | 视频无法取得可信时长或文件处理失败；核对有效视频流/文件 |
| 503 | 服务端ffprobe不可用；检查CLASSROOM_FFPROBE及运行预检 |

真实浏览器复现：`scripts/run-exp4-acceptance.ps1`。脚本建立独立MySQL/Redis，不写主业务库；执行后端测试、前端构建、真实Chromium、合成媒体和旧库重复升级。需要专用端口13319、16319、18089、15179空闲；浏览器模块/可执行文件通过PLAYWRIGHT_MODULE、EXP3_CHROMIUM_PATH指定。本机验收输出在`docs/20261011-sprint3-evidence-v1/`，不要把这些样例统计当成真实教学结论。

本轮功能及自动验收已通过。真实会议、展演、回顾和自然人批准资料未提供，仍需单独补齐。
