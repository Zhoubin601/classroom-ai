## 已确认的接入缺口

原生视觉发送方法 `vision/classroom_monitor.py:296` 的 `async_send_stream_report` 对独立真实后端发送合成零人帧，返回 HTTP 401：未登录或登录令牌已过期。

本次从当前源码通过 AST 提取实际发送方法执行，以避开 GPU/摄像头模型导入；仅将 `backend_url` 指向本轮真实后端。HTTP 传输未模拟、未替换，因此该结果是原生发送方法的实际网络结果，不是现场摄像头识别测试。

- 发送请求没有 `Authorization`。
- 当前帧载荷没有 `offeringId`。
- 失败异常被吞掉，未形成可见错误反馈。
- `frontend/src/api/index.ts:74` 的启动接口和 `frontend/dev/camera-plugin.mjs` 的 Python 启动路径没有贯通班次及认证上下文。

后端要求有效认证和明确班次；已认证却缺少班次的请求，本轮验证返回 400。故即使摄像头能出图，也不能认定识别数据能进入当前受保护的大屏和考勤业务。

建议后续优先贯通所选班次、受控认证、视觉发送与停止流程并增加错误反馈，再进行现场摄像头识别验收。本次任务为检查，未自动修改业务代码。

## 权限与冻结复测

- 三角色未授权班次的实时概览、趋势、学生状态、推流、重置均 403，拒绝请求不增加数据库记录；同名班次缓存隔离。
- 冻结班次写入 409，界面只读；旧页面启动失败后不推流，运行中被归档后自动停止；真实 MySQL 行锁并发归档后无新增记录。
- 教师督导仅读取本班名单，候选学生为空，界面隐藏名单编辑按钮；主任名单操作及人数同步通过。
- 空名单人数为 0，旁听编号不泄漏其他学生姓名或头像；原件下载内容类型和字节保持正确。
